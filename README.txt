# Landing Page - Gym

Este es un proyecto de práctica creado con HTML y CSS.

## Objetivo

Crear una landing page para un gimnasio ficticio, enfocada en presentar beneficios, planes, testimonio y un formulario de contacto.

## Tecnologías usadas

- HTML
- CSS
- Diseño responsive
- Flexbox
- CSS Grid

## Secciones

- Navegación
- Hero principal
- Beneficios
- Planes
- Testimonio
- Formulario de contacto
- Footer

## Estado

Proyecto terminado en versión 1.
